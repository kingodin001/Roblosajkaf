# RIFT STRIKE: MULTIVERSE

Игра для Roblox Studio на основе открытого проекта **Broken PvP** автора Dewan Mukto (MIT). Репозиторий предназначен для исходников, версий и дальнейшей разработки.

## Текущая версия: 0.4 (31.10.2026)
- Сохранены оригинальные PvP-карты, оружие, NPC и система раундов.
- Добавлены режимы **Зомби (PvE)**, **Спецоперация (PvE)** и **Паркур (16 этапов)**.
- Добавлены **Rift Tokens**, магазин улучшений скорости и прыжка, яйца и косметические спутники.
- В PvP бонусы скорости и прыжка не должны давать преимущества.
- Предусмотрено сохранение через Roblox DataStore, нуждается в проверке в Studio.

## Запуск
1. Скачайте файл `RIFT_STRIKE_MULTIVERSE_0.4_PARKOUR_PETS_SHOP.rbxl` из готовой сборки.
2. Откройте его через **Roblox Studio → File → Open from File**.
3. Нажмите **Play (F5)**, затем выберите режим в верхнем меню.

**Статус резервного копирования:** репозиторий только инициализирован. **Большой бинарный файл .rbxl ещё не загружен сюда**, поэтому GitHub пока не заменяет копию проекта на компьютере. Чтобы сохранить сборку, вручную перетащите .rbxl в репозиторий через **Add file → Upload files → Commit changes** (GitHub веб-интерфейс принимает отдельные файлы такого размера).

## Важные ограничения
- Сборка программно проверена на целостность, но требует проверки игровых сценариев в Roblox Studio.
- Перед публикацией требуется аудит сторонних звуков, моделей и ассетов на права использования.
