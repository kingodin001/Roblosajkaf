# RIFT STRIKE v0.5.1 — исправление входа (31.10.2026)

**Ошибка версии 0.5:** при запуске игрок оставался на наклонённой заставке Broken PvP с отсутствующими кнопками. Старый Play был скрыт, а новое меню показывалось лишь после события из старой заставки.

**Изменения версии 0.5.1:**
- Новый самостоятельный экран выбора режимов, который создаётся сразу при запуске клиента и не зависит от старого интро.
- Старая заставка и экран загрузки отключаются визуально.
- При выборе режима создаётся персонаж, если его нет; затем камера и управление переключаются на персонажа.
- PvP открывает выбор доступной карты; доступны Зомби, Спецоперации и Паркур.
- В игре есть кнопка возврата в меню режимов.
- 58 870 объектов оригинального проекта, оружие и карты сохранены.

**Проверка:** выполнена структурная проверка двоичного .rbxl и архива. Запуск в Roblox Studio не проверялся в среде подготовки, возможны дополнительные ошибки.

**Важно:** бинарный .rbxl не загружен в GitHub через подключение. Для резервного копирования скачайте ZIP из чата и загрузите извлечённый .rbxl в репозиторий через **Add file → Upload files**.
