# RIFT STRIKE: MULTIVERSE — v0.5

Дата: 31 октября 2026 года.

## Исправление входа и выбора карты

- Начальное состояние игрока: **MENU**, без автоматического запуска PvP.
- Одно главное меню RIFT STRIKE после загрузки, вместо старого Play из Broken PvP.
- Игрок выбирает один из четырёх режимов: PvP, Зомби, Спецоперации, Паркур.
- Для PvP игрок дополнительно выбирает одну из исходных карт: CityMap00, CityMap01, CityMap02, CityMap03, WarMap00, WarMap01, TestMap00 (если они доступны в исходном проекте).
- Выбор PvP-карты: один игрок переключает немедленно; несколько игроков — голосование большинства (карта общая для сервера).
- В новом раунде карта PvP не рандомизируется, продолжает использоваться выбранная.
- Меню режимов можно открыть повторно во время игры.
