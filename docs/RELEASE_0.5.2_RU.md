# RIFT STRIKE 0.5.2 — исправление запуска
Дата: 31.10.2026.

Проблема: в 0.5.1 главное меню открывалось, но переход к персонажу и управление могли не активироваться после выбора режима.

## Изменения
- Кнопки меню используют универсальный обработчик `Activated`.
- Меню ждёт подтверждения выбранного режима от сервера и появления персонажа.
- После подтверждения явно включаются Controls через PlayerModule, восстанавливаются камера и игровые элементы интерфейса.
- Добавлена резервная попытка создания персонажа через `SpawnPlayer`.
- При отсутствии подтверждения меню остаётся открытым и показывает диагностическое сообщение.
- Изменён только LocalScript `cutsceneHandler`, остальные скрипты и исходные 3D-карты не тронуты.

Файлы версии: `RIFT_STRIKE_MULTIVERSE_0.5.2_PLAY_FIX.rbxl`, `RIFT_STRIKE_0.5.2_PLAY_FIX.zip`.

**Статус:** проверены бинарная структура файла, неизменность остальных скриптов и ZIP. **Не проверено игровым запуском в Roblox Studio.** Для диагностики ошибок смотреть View/Window → Output и строки `[RIFT 0.5.2]`.
